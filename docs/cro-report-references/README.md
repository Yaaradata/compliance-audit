# UK CRO report references

UK documents used for the structure, wording and style of the CRO Report. No figure in the report comes from them.

UK banks do not publish their internal board papers, so none of these is an internal CRO paper. The nearest public examples are the CRO's review in an annual report, committee terms of reference that say what the CRO reports, and PRA expectations. The report format is built from them.

## Removed as not UK

The earlier version of the report also drew on two web articles, from eQomply and Tyson Martin, whose guidance was not UK-specific. They are no longer relied on, except that the "decisions first" layout came from them. PRA SS5/16 supports clear escalation to the board but does not prescribe that layout.
